### task router
 - 태스크 분류 
   - transaction_save_task (거래내역 등록)
   - transaction_search_task (거래내역 조회)
   - external_search_task (외부 검색)
   - other_task (일상 대화)

### transaction_save_task
 - sub agent 호출
   - RDB(postgres) 저장
     - 질문에서 entity 추출 후 SQL 호출
       - 거래 유형, 거래 항목, 거래 금액
       - SQLDatabase.from_uri("..").run("..")
         - ![db](./img/db.png) 
   - embedding(chroma) 저장
       - ~~~
               Document(
                    page_content=f"{type} {name} {amount}",
                    metadata={
                        "type": type,
                        "name": name,
                        "amount": amount,
                        "user_id": user_id,
                    },
                )
         ~~~ 
 - HITL
   - 사용자의 feedback을 받고 llm 호출을 통해서 동의여부 체크
   - 애메한 경우 미동의
